แนวคิดเชิงคำนวณ (Computational Thinking)

เกม ROBO DELIVERY ออกแบบมาเพื่อฝึกกระบวนการคิด 4 เสาหลักของการคิดเชิงคำนวณ:

1. Decomposition (การแบ่งย่อยปัญหา)

การแยกปัญหาใหญ่ให้เป็นส่วนย่อยๆ
ในเกม: แทนที่จะมองว่า "ต้องเอาของไปส่งให้ได้" เราแบ่งเป็นก้าวย่อยๆ คือ เดินหน้า -> เลี้ยวซ้าย -> เก็บของ -> เดินหน้า -> ส่งของ

2. Pattern Recognition (การหารูปแบบ)

การหารูปแบบที่ซ้ำกันหรือมีความคล้ายคลึงกัน
ในเกม: การสังเกตว่าต้องทำขั้นตอน "เดินหน้า แล้ว เลี้ยวขวา" ซ้ำกันหลายๆ ครั้งในเส้นทางซิกแซก

3. Abstraction (การคิดเชิงนามธรรม)

การมุ่งความสนใจไปที่ข้อมูลสำคัญ และตัดรายละเอียดที่ไม่จำเป็นทิ้ง
ในเกม: เราสนใจแค่ตำแหน่งพัสดุและทางเดิน ไม่ต้องสนใจว่าพัสดุคืออะไรหรือหุ่นยนต์สีอะไร มองเป็นเพียงระบบ Grid

4. Algorithm Design (การออกแบบอัลกอริทึม)

การวางลำดับขั้นตอนการแก้ปัญหาที่ชัดเจน
ในเกม: การนำบล็อกคำสั่งมาเรียงต่อกันตั้งแต่ต้นจนจบ เพื่อให้หุ่นยนต์ทำงานได้อย่างถูกต้องและมีประสิทธิภาพที่สุด

💡 คำแนะนำการเล่น (5-Step Learning Loop):
1. สังเกต (Observe) เส้นทาง > 2. วางแผน (Plan) > 3. เรียงคำสั่ง (Arrange) > 4. ทดลองรัน (Test) > 5. แก้ไขข้อผิดพลาด (Debug)
